4️⃣  CONFIGURAÇÕES
================================================================================

O bot tem um arquivo chamado "config.json" que você pode personalizar.

COMO MODIFICAR:
1. Abra a pasta do bot
2. Procure por: "config.json"
3. Clique com botão direito e escolha "Abrir com... Bloco de Notas"
4. Modifique os valores conforme desejado
5. Salve (Ctrl+S)
6. Execute o bot novamente

OPÇÕES DISPONÍVEIS:
----------------------------------

"velocidade_clique": 0.5
  → Quanto mais ALTO, mais LENTO é o clique (em segundos)
  → Padrão: 0.5 (recomendado)
  → Valores: 0.1 a 2.0

"intervalo_verificacao": 2
  → Quanto tempo esperar antes de procurar novo botão (em segundos)
  → Padrão: 2 (recomendado)
  → Valores: 1 a 10

"modo_debug": true
  → Se TRUE: Bot salva capturas de tela para debug
  → Se FALSE: Bot roda mais rápido
  → Padrão: true
  → Valores: true ou false

"tempo_maximo_missao": 300
  → Tempo máximo para completar uma missão (em segundos)
  → Padrão: 300 (5 minutos)
  → Valores: 60 a 600

"delay_entre_missoes": 5
  → Tempo de espera entre uma missão e outra (em segundos)
  → Padrão: 5 (recomendado)
  → Valores: 1 a 30

"numero_missoes_antes_pausa": 10
  → Quantas missões completar antes de fazer uma pausa
  → Padrão: 10
  → Valores: 5 a 100

"tempo_pausa_minutos": 5
  → Quanto tempo pausar depois de N missões (em minutos)
  → Padrão: 5
  → Valores: 1 a 60


EXEMPLO DE CONFIGURAÇÃO RÁPIDA:
----------------------------------
{
  "velocidade_clique": 0.3,
  "intervalo_verificacao": 1,
  "modo_debug": false,
  "tempo_maximo_missao": 300,
  "delay_entre_missoes": 2,
  "numero_missoes_antes_pausa": 20,
  "tempo_pausa_minutos": 10
}

5️⃣  TROUBLESHOOTING (RESOLVENDO PROBLEMAS)
================================================================================

PROBLEMA 1: "Python não está instalado"
----------------------------------
Solução:
1. Acesse: https://www.python.org/downloads/
2. Baixe e instale Python 3.10+
3. ⚠️  IMPORTANTE: Marque "Add Python to PATH"
4. Reinicie o computador
5. Tente novamente


PROBLEMA 2: "Arquivo requirements.txt não encontrado"
----------------------------------
Solução:
1. Certifique-se de que extraiu TODA a pasta do bot
2. Não extraia apenas alguns arquivos
3. Baixe novamente se necessário


PROBLEMA 3: O bot não detecta os botões
----------------------------------
Possíveis causas:
✓ Resolução da tela diferente (tente 1920x1080)
✓ Interface do jogo modificada
✓ Bot procurando no lugar errado

Soluções:
1. Verifique a resolução: Clique direito na tela → Configurações de tela
2. Aumente o valor de "intervalo_verificacao" em config.json
3. Reduza o valor de "velocidade_clique"
4. Se o modo_debug estiver TRUE, verifique a pasta "screenshots/"


PROBLEMA 4: O bot é muito lento
----------------------------------
Soluções:
1. Reduza o valor de "intervalo_verificacao" em config.json
2. Reduza o valor de "velocidade_clique"
3. Aumente o valor de "delay_entre_missoes"
4. Mude "modo_debug" para false


PROBLEMA 5: O computador trava/fica lento
----------------------------------
Soluções:
1. Aumente o valor de "delay_entre_missoes"
2. Aumente o valor de "intervalo_verificacao"
3. Ative "modo_debug": false (para não salvar screenshots)
4. Feche outros programas que usam muita RAM


PROBLEMA 6: "Access Denied" ou erro de permissão
----------------------------------
Solução:
1. Clique com botão DIREITO em "instalar_e_executar.bat"
2. Escolha "Executar como administrador"


PROBLEMA 7: Erro na hora de instalar dependências
----------------------------------
Solução:
1. Abra o Prompt de Comando (Windows + R, digitar "cmd")
2. Digite: pip install --upgrade pip
3. Aguarde terminar
4. Digite: pip install -r requirements.txt
5. Tente executar o bot novamente
